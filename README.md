# Lo-Fi League

Laid-back 7 a side soccer. Pass, shoot and take it easy. For Android and the browser.

Play in the browser or download the Android APK from the game page: https://bclark10121-cloud.github.io/lo-fi-league/

More games: https://bclark10121-cloud.github.io/

## What is in this repo

- `docs/`: the game page, the browser build, the Android APKs, the release notes and the privacy page.
- `BACKLOG.md`: what is done and what is planned.
- `CREDITS.md`: outside assets and their licences.

Older versions and their APKs are on the Releases page. The game's source is kept in a private repo.
