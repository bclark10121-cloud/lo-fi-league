# Lo-Fi League v0.2.2

Play with only an Xbox controller. Safer saves. Gameplay is the same as v0.2.1.

## New in this version

- Xbox controller in every menu. A chooses the highlighted button and B goes back. Before, A did nothing on the title card, so you needed a tap, a click or a key to start.
- B goes back from the game modes, the club picker and the league table. B also closes the Menu.
- View and Menu both open and close the Menu.
- The title card, How to play and the game page use the Xbox button names. The game page shows how to connect an Xbox controller on Android and in the browser.
- Saves keep a backup. If the save file is ever cut off, the game loads the last good save instead of starting over.
- A save from a newer version is never overwritten by an older one. Your counters can never load as silly numbers.
- The browser test switches now work only for tests, never for players.
- Built on the shared kit 1.5.0 from `game-standards`.
- Version code 5. Signed with the real key. Installs over v0.1.1, v0.2.0 and v0.2.1. Your season and records stay.

## Test checklist

1. On a phone with v0.2.1: install v0.2.2 over it. No uninstall needed. Your league table and records are still there.
2. Pair an Xbox controller with the phone (see the game page). Open the game. The touch buttons hide when you use the controller.
3. With only the controller: press A on Start, pick Exhibition with A, press B to go back, pick League with A, pick a club and play a match.
4. In a match: View opens the Menu and A on Resume closes it. Menu opens it again and B closes it.
5. At full time, A picks the highlighted button.
6. In the browser: connect the controller, open Play in your browser, press any button once, then repeat steps 3 to 5.
7. Play a league match to full time, close the game and open it again. The League button reads the next matchday.
8. The game page shows one line under the buttons: Version 0.2.2. Release notes · Backlog · Source on GitHub.

## Known limits

- Tested by the rules check, a test bot (a full season and 6 matches), a pretend Xbox controller test, a browser test and an end-to-end test of two full seasons in headless Chrome. Not tested on a real phone, with a real controller or with speakers.
- Other controllers that the phone or browser sees as a standard gamepad use the same buttons. Only the Xbox layout is tested.
- In a browser a save needs about half a second to reach storage. Closing the tab in that half second can lose the last match.
