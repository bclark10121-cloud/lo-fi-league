# Lo-Fi League v0.3.0

A standards release. No new soccer. The shared Settings menu with an Opponent choice, five save slots, Tester tools, controls for the device you use, rumble, a new icon and a privacy page.

## Five minute test

1. Install the APK over v0.2.3. The new icon is a ball wearing headphones. The title card says Version 0.3.0. Your record and your season are still there, in slot 1.
2. On the phone the title card shows the touch controls only. Connect an Xbox controller and press a button: the line changes to the controller controls.
3. Under Start you now have Slot 1 and Settings. Open Settings: Music and Sound have five levels, then Frame rate, Rumble, Opponent, Controls, Text size and Reset settings. Text size starts on Larger on a phone, as the old Large text did.
4. Set Opponent to Easy. Play an exhibition. The other club runs, tackles and shoots a little slower. Score a goal: the phone buzzes.
5. Open the Menu. It reads Resume, Settings, How to play, Restart match, Title. Press Restart match once: it says Press again to restart.
6. Mid-match, turn the controller off. The Menu opens and the match is paused.
7. Open Settings, Tester tools, enter your code. Try Jump to matchday 7, then Copy bug report and paste it into any app.
8. Press Slot 1 on the title card. Pick slot 2: a fresh game starts there. Go back to slot 1: your record is as you left it.

## New in this version

- Settings from the shared kit. Music and Sound as levels in five steps, Full screen in the browser, Frame rate, Rumble, Opponent, Controls, Text size (Normal, Large, Larger) and Reset settings. Every change saves at once. There is no Save button.
- Opponent: Easy, Normal or Hard. It sets how fast the computer club runs, tackles and shoots. Your own club never changes.
- Five save slots. Each slot has its own record and league season. Delete a slot with two presses. Your old save moved into slot 1. Your old Sound, Music and Text choices moved into Settings.
- The title card shows the controls for the device you use: keys, Xbox controller or touch. How to play still shows all three.
- The match pauses when the controller you play with disconnects, as it does when the game loses focus.
- The Menu reads Resume, Settings, How to play, Restart match, Title, the same order every game will use. Sound, Music and Text moved into Settings.
- Restart match and Start over in the league need a second press. Title in a league match still asks once, because a quit league match does not count.
- Rumble: the phone buzzes and the controller rumbles on a goal and when a tackle wins or loses you the ball. Switch it off in Settings.
- Tester tools behind a code in Settings, for test builds: goals, the clock, the second half, jumps through the league, the Opponent, the save tools and Copy bug report.
- A new icon, drawn large and sharp, with the adaptive and themed icons on Android.
- A privacy page. The game collects no data and the Android app does not ask for the internet permission.
- Every release now gets a GitHub Release with its APK. The game page keeps the newest two APKs.
- The source moved to a private repo. The public repo keeps the game page, the builds, the release notes and the backlog.

## Shared kit

Built with kit 1.9.1.

## Install

Version code 7. Signed with the real key. v0.3.0 installs over v0.1.1 and every later version. Your record and your season stay. If you still have v0.1.0, uninstall it first. It used a test signature.

## Full test checklist

1. Settings fits a phone held sideways, a tablet and a desktop window, with Text size Larger too.
2. Change Music and Opponent, reload the browser page: both stay set.
3. Reset settings asks first. The second press puts every setting back.
4. The slot list fits a phone. Delete asks first. Deleting the slot in use moves you to another used slot.
5. Keyboard only: Esc opens the Menu, the arrows and Enter reach Settings and Tester tools.
6. Controller only: A chooses, B goes back from Settings, the slot list and Tester tools.
7. The league quit check, the remembered mode and club and the goal scorers at full time work as in v0.2.3.
8. Older versions are on the repo's Releases page, each with its APK.
