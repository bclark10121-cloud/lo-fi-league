# Lo-Fi League v0.6.1

A fix for v0.6.0: Play and Settings on the start screen opened nothing you could see.

## Five minute test

1. Install the APK over v0.6.0. Your saves stay.
2. On the start screen press Play. The Save slots list shows over the start screen.
3. Pick a slot. How do you want to play shows. Play a few minutes of an Exhibition.
4. Back on the start screen press Settings. The Settings list shows. Open Controls and go Back.
5. Try both with touch, a mouse, keys and a controller.

## What was wrong

The start screen sat on its own layer above the Save slots list and Settings. Both opened behind it, so the screen looked frozen. Quit worked because it sits on the start screen itself. The start screen now sits under those panels.

## New in this version

- Play and Settings on the start screen work again.
- A new check confirms the Save slots list and Settings sit above the start screen. The old checks read the game's state, not what was on screen, so they missed this.

Version 0.6.1 installs over 0.6.0 and keeps your saves.
