# Lo-Fi League v0.7.3

Lo-Fi League now runs on Godot 4.7.2 (G6.19). Nothing about play changes. This is the engine move only, so your Flow notes from the playtest sweep come in their own release once you say what felt off.

## Five minute test

1. Install the APK over v0.7.2. Your saves, records and league stay.
2. Open the game. The title track plays and the title card shows.
3. Play an exhibition match for a minute. Pass, shoot, through ball and skill move work as before.
4. Open Settings and the Tester tools. Both open as before.

## Changed

- Godot 4.7.2, from 4.6.3. No change you should notice.

## Shared kit

Kit 1.15.0, unchanged.

## Install

Version 0.7.3 installs over 0.7.2 and keeps your saves.

## Test checklist

- [ ] Plays as before on your phone and the Retroid.

## Judgment calls

1. The Flow work you marked Needs work waits for your notes. Nothing in play was tuned in this release.
2. One test, `flow_check`, passed 4 of 6 runs. It counts how often the computer wins the ball in 200 random tackles, and the pass line sits right at the usual count (50). It failed the same way on Godot 4.6. Making it steady (a fixed random seed) is a small test-only fix for the next release.

## Tested and not tested

Tested on the cloud test machine with Godot 4.7.2:

- COMMON, SECRETS, SAVESTORE, DEBUGMENU, SETTINGS_SLOTS and STANDARDS checks ok. The rules check (0 failed), six bot matches and a full bot season ok.
- Browser tests on the new web build: the game test and the Xbox controller test print `errors []`. The audio test prints `AUDIO ok`.
- The build check: the web build and the APK carry the Tester tools gate and the APK asks for no internet.
