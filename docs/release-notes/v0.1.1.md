# Lo-Fi League v0.1.1

Signing update. The game is the same as v0.1.0.

## New in this version

- The Android APK is signed with BC's real key (`wandervalley.jks`). Future versions install over this one.
- Version code 2.

## Test checklist

1. On a phone: uninstall Lo-Fi League v0.1.0 if it is installed. It used a test signature.
2. Open the game page. Tap Download for Android. Install `LoFiLeague-v0.1.1.apk`.
3. Open the game. The title card shows Version 0.1.1.
4. Play the v0.1.0 checklist: https://bclark10121-cloud.github.io/lo-fi-league/release-notes/v0.1.0.md
5. In the browser: open the game page, tap Play in your browser. The title card shows Version 0.1.1.

## Known limits

- Tested by a test bot, a rules check and headless Chrome. Not tested on a real phone, a controller or with speakers.
- No offside, fouls, free kicks, penalties or substitutions yet.
