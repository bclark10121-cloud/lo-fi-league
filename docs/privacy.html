Lo-Fi League: privacy

This game collects no data.

  • No accounts and no sign-in.
  • No ads and no trackers.
  • The game makes no network calls. The Android app does not ask for the internet permission.
  • Your settings and saved games stay on your device. Deleting the app or clearing this site's data in your browser removes them.

This page is hosted on GitHub Pages. GitHub may log visits to the page itself, as any web host does. The game sends nothing.
